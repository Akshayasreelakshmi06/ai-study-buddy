# AI Study Buddy 📚

An AI-powered study assistant built with Python, Streamlit, and Google's Gemini API to help students learn more effectively.

## Features

- 💡 Explain a Topic — Get easy-to-understand explanations.
- 📝 Study Notes — Generate concise study notes.
- 🎯 Take a Quiz — Test your understanding.
- 🃏 Revision Flashcards — Revise important concepts.
- 📅 Personal Study Planner — Organize your study schedule.
- 📊 Study Progress Dashboard — Track your learning progress.

## Tech Stack

- Python
- Streamlit
- Google Gemini API

## Run Locally

1. Clone this repository.
2. Install the dependencies:

   `pip install -r requirements.txt`

3. Add your Gemini API key to a `.env` file using the environment variable `GEMINI_API_KEY`.
4. Start the app:

   `streamlit run app.py`

## Security

Never publish your API key or commit your `.env` file to GitHub.
